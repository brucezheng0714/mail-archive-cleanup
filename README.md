# Mail Archive Cleanup — landing page

Marketing landing page for **Mail Archive Cleanup**, a macOS app that archives
Apple Mail to any drive and frees up local disk space.

- **Product:** https://vexzheng.gumroad.com/l/afquw
- Static single page (`index.html` + `assets/`), no build step.

## Deploy (GitHub Pages)

1. Push this folder to a **public** GitHub repo.
2. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `/root`**.
3. Live at `https://<username>.github.io/<repo>/` after ~1–2 min.
